# BeMyBuddy — Next.js Starter MVP

Starter frontend navegable con datos mock para el MVP V1 de BeMyBuddy.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Instalar

```bash
npm install
npm run dev
```

Luego abre:

```bash
http://localhost:3000
```

## Qué incluye

- Welcome
- Choose Category
- Personal Context
- AI Match
- Buddy Summary
- First Chat
- Dashboard con tabs internas
- Memoria mock
- Ajustes mock
- Design tokens BeMyBuddy
